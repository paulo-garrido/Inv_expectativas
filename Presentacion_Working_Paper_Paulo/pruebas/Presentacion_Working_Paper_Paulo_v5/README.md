# Presentación Working Paper — v5

Versión estructural depurada para exposición de 20 minutos.

## Archivos

- `presentacion_anclaje_v5.qmd`: presentación Quarto RevealJS.
- `custom_v5.scss`: estilo visual institucional.
- `assets/`: logos y figuras.

## Renderizar

```bash
quarto render presentacion_anclaje_v5.qmd
```

## Presentación

- `F`: pantalla completa.
- `S`: speaker view.
- Flechas o espacio: avanzar.

## Exportar a PDF

Abrir el HTML y usar:

```text
?print-pdf
```

Luego imprimir en Chrome como PDF en horizontal, márgenes ninguno y gráficos de fondo activados.
